# i18n 设计文档（SSOT 单一事实来源）

本文档定义前后端共享的国际化（i18n）单一事实来源（SSOT）设计、目录结构、规范与集成方式，确保跨应用、跨平台的翻译一致性与可维护性。

## 1. 目标与范围

### 1.1 核心目标

- **单一事实来源**：所有翻译文案集中在 `packages/i18n` 中统一维护与发布
- **位置替换策略**：服务端返回英文 `msg` 并用 `{}` 标记参数位置，前端按位置提取参数值后替换到对应语言的模板中
- **统一的 t 函数**：只有一个 `t` 函数，通过参数类型自动判断是 UI 文案还是 API 错误处理
- **HTTP 层统一拦截**：在 HTTP 拦截器层面统一调用 `t(code, msg)` 处理 API 错误
- **优雅降级**：未找到翻译时，直接显示服务端的英文 `msg`（已包含实际值）

### 1.2 适用范围

- **前端应用**：Next.js (apps/biz)、Vite (apps/chat) 等所有前端项目
- **后端 API**：Go 后端 (chatbot/backend) 返回的所有错误码和业务消息
- **组件库**：React 组件库 (packages/ui)

## 2. 核心设计原理

### 3.2 关键设计点

1. **`code` 字段作为分组**：所有 API 错误码统一放在 `code` 节点下
2. **嵌套结构**：使用对象嵌套而非平铺的点号键名
3. **访问方式**：通过点号路径访问，如 `t("button.submit")` 或 `t("code.FILE_NOT_FOUND", msg)`

## 4. 核心 API 设计

### 4.1 统一的 t 函数

```typescript
export type Lang = "en" | "zh";

export interface I18n {
  /**
   * 统一的翻译函数，支持两种调用方式：
   * 
   * 1. UI 文案翻译（命名参数）：
   *    t("button.submit") → "提交"
   *    t("table.pagination.total", { total: "42" }) → "共 42 条"
   * 
   * 2. API 错误翻译（位置参数，从服务端 msg 提取）：
   *    t("code.FILE_NOT_FOUND", "File {document.txt} Not Found") → "文件 document.txt 不存在"
   *    t("code.UNKNOWN_CODE", "Some error message") → "Some error message"（未找到 code 时返回原 msg）
   * 
   * @param key - 翻译键或错误码（API 错误需要加 "code." 前缀）
   * @param paramsOrMsg - 命名参数对象 或 服务端消息字符串
   */
  t(key: string, paramsOrMsg?: Record<string, string> | string): string;
  
  /**
   * 当前语言
   */
  lang: Lang;
}

/**
 * 创建 i18n 实例
 */
export function createI18n(lang?: Lang): I18n;
```

### 4.2 核心算法

#### getByPath (嵌套对象访问)

```typescript
/**
 * 通过点分隔的路径访问嵌套对象
 * 示例: getByPath({ button: { submit: "提交" } }, "button.submit") → "提交"
 */
function getByPath(obj: any, path: string): any {
  const keys = path.split(".");
  let value = obj;
  for (const key of keys) {
    value = value?.[key];
    if (value === undefined) return undefined;
  }
  return value;
}
```

#### extractParams (参数提取)

从服务端消息中提取 `{}` 包裹的参数值。

```typescript
/**
 * 从服务端 msg 中提取参数值
 * 示例: "File {document.txt} Not Found {2024-06-01}" → ["document.txt", "2024-06-01"]
 */
function extractParams(msg: string): string[] {
  const pattern = /\{([^}]+)\}/g;
  const params: string[] = [];
  let match: RegExpExecArray | null;
  
  while ((match = pattern.exec(msg)) !== null) {
    params.push(match[1]);
  }
  
  return params;
}
```

#### replaceByPosition (位置替换)

将提取的参数值按位置替换到翻译模板中。

```typescript
/**
 * 按位置将参数值替换到模板中
 * 示例: ("文件 {filename} 不存在", ["document.txt"]) → "文件 document.txt 不存在"
 */
function replaceByPosition(template: string, params: string[]): string {
  let index = 0;
  
  const result = template.replace(/\{([^}]+)\}/g, (match, varName) => {
    if (index >= params.length) {
      console.warn(`参数不足: 模板需要变量 "${varName}"，但只提供了 ${params.length} 个参数`);
      return match; // 保留原样
    }
    return params[index++];
  });
  
  return result;
}
```

#### replaceByName (命名参数替换)

将命名参数替换到 UI 文案中。

```typescript
/**
 * UI 文案中的命名参数替换
 * 示例: ("共 {total} 条", { total: "42" }) → "共 42 条"
 */
function replaceByName(template: string, params: Record<string, string>): string {
  return template.replace(/\{([^}]+)\}/g, (match, varName) => {
    if (varName in params) {
      return params[varName];
    }
    console.warn(`参数 "${varName}" 未提供`);
    return match;
  });
}
```

#### 统一的 t 函数实现

```typescript
/**
 * 统一的翻译函数
 */
function t(key: string, paramsOrMsg?: Record<string, string> | string): string {
  // 1. 查找翻译模板
  let template = getByPath(currentCatalog, key);
  
  if (!template && lang !== "en") {
    template = getByPath(fallbackCatalog, key);
  }
  
  // 2. 判断调用方式
  if (typeof paramsOrMsg === "string") {
    // API 错误模式: t("code.FILE_NOT_FOUND", "File {doc.txt} Not Found")
    if (!template) {
      // 未找到翻译，直接返回服务端 msg
      return paramsOrMsg;
    }
    // 从 msg 中提取参数值，按位置替换到模板
    const params = extractParams(paramsOrMsg);
    return replaceByPosition(template, params);
  } else {
    // UI 文案模式: t("button.submit") 或 t("table.total", { total: "42" })
    if (!template) {
      console.warn(`翻译键 "${key}" 未找到`);
      return key;
    }
    if (!paramsOrMsg) return template;
    return replaceByName(template, paramsOrMsg);
  }
}
```

## 5. 前端集成

### 5.1 HTTP 拦截器统一处理

在 HTTP 拦截器层面统一调用 `t(code, msg)` 处理 API 错误：

```typescript
// utils/request.ts
import axios from "axios";
import { toast } from "sonner";
import { useI18n } from "@/contexts/I18nContext";

// 创建 axios 实例
export const apiClient = axios.create({
  baseURL: process.env.NEXT_PUBLIC_API_URL,
  timeout: 30000,
});

// 响应拦截器
apiClient.interceptors.response.use(
  (response) => response,
  (error) => {
    // 从 context 获取 i18n 实例
    const { i18n } = useI18n();
    const { t } = i18n;
    
    // 提取 code 和 msg
    const code = error.response?.data?.code;
    const msg = error.response?.data?.msg || error.message;
    
    if (code) {
      // 有 code：调用 t("code.XXX", msg) 进行翻译
      const translatedMsg = t(`code.${code}`, msg);
      toast.error(translatedMsg);
    } else {
      // 无 code：直接展示 msg
      toast.error(msg || "Unknown error");
    }
    
    return Promise.reject(error);
  }
);
```

**关键点**：

- HTTP 拦截器层统一处理，业务代码无需关心翻译
- 调用 `t("code.FILE_NOT_FOUND", "File {doc.txt} Not Found")`
- 如果找到 `code.FILE_NOT_FOUND` 的翻译模板，提取 msg 中的参数并替换
- 如果未找到翻译，直接返回 msg

### 5.2 React Context 集成

```typescript
// contexts/I18nContext.tsx
import React, { createContext, useContext, useState, useEffect, ReactNode } from "react";
import { createI18n, Lang, I18n } from "@kssbox/i18n";

interface I18nContextValue {
  i18n: I18n;
  lang: Lang;
  setLang: (lang: Lang) => void;
}

const I18nContext = createContext<I18nContextValue | null>(null);

const STORAGE_KEY = "app_lang";

export function I18nProvider({ children, defaultLang = "en" }: { 
  children: ReactNode; 
  defaultLang?: Lang;
}) {
  const getInitialLang = (): Lang => {
    if (typeof window === "undefined") return defaultLang;
    
    const stored = localStorage.getItem(STORAGE_KEY);
    if (stored === "en" || stored === "zh") return stored;
    
    const browserLang = navigator.language.toLowerCase();
    if (browserLang.startsWith("zh")) return "zh";
    return "en";
  };
  
  const [lang, setLangState] = useState<Lang>(getInitialLang);
  const [i18n, setI18n] = useState(() => createI18n(lang));
  
  const setLang = (newLang: Lang) => {
    setLangState(newLang);
    setI18n(createI18n(newLang));
    
    if (typeof window !== "undefined") {
      localStorage.setItem(STORAGE_KEY, newLang);
      document.documentElement.lang = newLang;
    }
  };
  
  useEffect(() => {
    if (typeof window !== "undefined") {
      document.documentElement.lang = lang;
    }
  }, [lang]);
  
  return (
    <I18nContext.Provider value={{ i18n, lang, setLang }}>
      {children}
    </I18nContext.Provider>
  );
}

export function useI18n() {
  const context = useContext(I18nContext);
  if (!context) {
    throw new Error("useI18n must be used within I18nProvider");
  }
  return context;
}
```

### 5.3 组件中使用

```typescript
// components/LoginForm.tsx
import { useState } from "react";
import { useI18n } from "@/contexts/I18nContext";
import { login } from "@/services/authService";
import { Button, Input, Label } from "@/components/ui";

export function LoginForm() {
  const { i18n } = useI18n();
  const { t } = i18n;
  
  const [email, setEmail] = useState("");
  const [password, setPassword] = useState("");
  const [errors, setErrors] = useState<Record<string, string>>({});
  
  const validate = () => {
    const newErrors: Record<string, string> = {};
    
    if (!email) {
      newErrors.email = t("form.email.error.required");
    } else if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email)) {
      newErrors.email = t("form.email.error.invalid");
    }
    
    if (!password) {
      newErrors.password = t("form.password.error.required");
    } else if (password.length < 8) {
      newErrors.password = t("form.password.error.minLength");
    }
    
    setErrors(newErrors);
    return Object.keys(newErrors).length === 0;
  };
  
  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault();
    
    if (!validate()) return;
    
    try {
      await login({ email, password });
      toast.success(t("message.success.loggedIn"));
    } catch (error) {
      // HTTP 拦截器已经统一处理了错误翻译和 toast
      // 这里无需额外处理
    }
  };
  
  return (
    <form onSubmit={handleSubmit} className="space-y-4">
      <h1 className="text-2xl font-bold">{t("title.login")}</h1>
      
      <div>
        <Label htmlFor="email">{t("form.email.label")}</Label>
        <Input
          id="email"
          type="email"
          value={email}
          onChange={(e) => setEmail(e.target.value)}
          placeholder={t("form.email.placeholder")}
          className={errors.email ? "border-red-500" : ""}
        />
        {errors.email && (
          <p className="text-sm text-red-500 mt-1">{errors.email}</p>
        )}
      </div>
      
      <div>
        <Label htmlFor="password">{t("form.password.label")}</Label>
        <Input
          id="password"
          type="password"
          value={password}
          onChange={(e) => setPassword(e.target.value)}
          placeholder={t("form.password.placeholder")}
          className={errors.password ? "border-red-500" : ""}
        />
        {errors.password && (
          <p className="text-sm text-red-500 mt-1">{errors.password}</p>
        )}
      </div>
      
      <div className="flex gap-2">
        <Button type="submit">{t("button.submit")}</Button>
        <Button type="button" variant="outline">{t("button.cancel")}</Button>
      </div>
    </form>
  );
}
```

### 6.2 API 响应格式化

```go
// chatbot/backend/utils/response_util.go
package utils

import (
    "fmt"
    "net/http"
    "strings"
    
    "github.com/gin-gonic/gin"
    "yourproject/config"
)

type ApiResponse struct {
    Code string      `json:"code"`
    Msg  string      `json:"msg"`
    Data interface{} `json:"data"`
}

type ApiError struct {
    Code   config.ErrorCode
    Values []string
}

func (e *ApiError) Error() string {
    return fmt.Sprintf("API Error: %s", e.Code)
}

func NewApiError(code config.ErrorCode, values ...string) *ApiError {
    return &ApiError{
        Code:   code,
        Values: values,
    }
}

// FormatMessage 格式化消息（将参数值用 {} 包裹）
func FormatMessage(template string, values []string) string {
    msg := template
    for _, value := range values {
        msg = strings.Replace(msg, "%s", fmt.Sprintf("{%s}", value), 1)
    }
    return msg
}

// ResponseError 返回错误响应
func ResponseError(c *gin.Context, err error, statusCode int) {
    var code config.ErrorCode
    var msg string
    
    if apiErr, ok := err.(*ApiError); ok {
        code = apiErr.Code
        msg = getErrorMessage(apiErr.Code, apiErr.Values)
    } else {
        code = config.CodeInternalServerError
        msg = err.Error()
    }
    
    c.JSON(statusCode, ApiResponse{
        Code: string(code),
        Msg:  msg,
        Data: nil,
    })
}

// getErrorMessage 根据错误码获取英文消息模板并填充参数
func getErrorMessage(code config.ErrorCode, values []string) string {
    templates := map[config.ErrorCode]string{
        config.CodeFileNotFound:     "File %s not found",
        config.CodeFileTooLarge:     "File %s exceeds maximum size %s",
        config.CodeFileUploadFailed: "Failed to upload file %s: %s",
        
        config.CodeInvalidToken:     "Invalid or expired token",
        config.CodeTokenExpired:     "Token expired at %s",
        config.CodePermissionDenied: "Permission denied for operation %s",
        
        config.CodeUserNotFound:      "User %s not found",
        config.CodeUserAlreadyExists: "User with email %s already exists",
        
        config.CodeChatbotNotFound: "Chatbot %s not found",
        config.CodeChatbotDisabled: "Chatbot %s is currently disabled",
        
        config.CodeKBNotFound:    "Knowledge base %s not found",
        config.CodeKBParseFailed: "Failed to parse document %s: %s",
        
        config.CodeBadRequest:          "Bad request",
        config.CodeUnauthorized:        "Unauthorized",
        config.CodeForbidden:           "Forbidden",
        config.CodeNotFound:            "Resource not found",
        config.CodeInternalServerError: "Internal server error",
    }
    
    template, ok := templates[code]
    if !ok {
        return string(code)
    }
    
    return FormatMessage(template, values)
}

func ResponseSuccess(c *gin.Context, data interface{}) {
    c.JSON(http.StatusOK, ApiResponse{
        Code: "200",
        Msg:  "Success",
        Data: data,
    })
}
```

## 8. FAQ

### Q1: 为什么要合并 api.json 和 ui.json？

**A**: 简化架构和使用：

1. **统一入口**：只有一个 `t` 函数，无需区分 `t` 和 `tAPI`
2. **HTTP 层统一处理**：拦截器直接处理所有 API 错误，业务代码无感知
3. **减少文件数量**：从 4 个文件（en/ui, en/api, zh/ui, zh/api）减少到 2 个（en.json, zh.json）
4. **通过 group 隔离**：使用 `code` 字段区分 API 错误，结构清晰

### Q2: t 函数如何区分 UI 文案和 API 错误？

**A**: 通过第二个参数的类型判断：

- **对象参数** → UI 文案：`t("button.submit")` 或 `t("table.total", { total: "42" })`
- **字符串参数** → API 错误：`t("code.FILE_NOT_FOUND", "File {doc.txt} Not Found")`

### Q3: 为什么 API 错误要加 "code." 前缀？

**A**: 明确标识这是 API 错误码，与 UI 文案区分：

- `t("code.FILE_NOT_FOUND", msg)` → 从 `code.FILE_NOT_FOUND` 路径查找翻译
- JSON 中对应：`{ "code": { "FILE_NOT_FOUND": "文件 {filename} 不存在" } }`

### Q4: HTTP 拦截器中如何获取 i18n 实例？

**A**: 有两种方案：

**方案 1**：通过 Context Hook（推荐用于 React 组件中创建的请求）

```typescript
// 在组件内部
const { i18n } = useI18n();
const { t } = i18n;

// 但拦截器是全局的，无法直接在拦截器中调用 useI18n()
```

**方案 2**：创建全局 i18n 实例（推荐）

```typescript
// utils/i18n.ts
import { createI18n } from "@kssbox/i18n";

// 创建全局实例
let globalI18n = createI18n("en");

export function getGlobalI18n() {
  return globalI18n;
}

export function setGlobalLang(lang: Lang) {
  globalI18n = createI18n(lang);
}

// utils/request.ts
import { getGlobalI18n } from "./i18n";

apiClient.interceptors.response.use(
  (response) => response,
  (error) => {
    const { t } = getGlobalI18n();
    const code = error.response?.data?.code;
    const msg = error.response?.data?.msg;
    
    if (code) {
      const translatedMsg = t(`code.${code}`, msg);
      toast.error(translatedMsg);
    } else {
      toast.error(msg || "Unknown error");
    }
    
    return Promise.reject(error);
  }
);

// contexts/I18nContext.tsx
import { setGlobalLang } from "@/utils/i18n";

export function I18nProvider({ children }: { children: ReactNode }) {
  const setLang = (newLang: Lang) => {
    setGlobalLang(newLang); // 同步更新全局实例
    // ...其他逻辑
  };
  
  // ...
}
```

### Q5: 业务代码需要手动处理 API 错误吗？

**A**: **不需要**。HTTP 拦截器已经统一处理了错误翻译和 toast 显示：

```typescript
// ✅ 推荐：简洁的业务代码
const handleSubmit = async () => {
  try {
    await login({ email, password });
    toast.success(t("message.success.loggedIn"));
  } catch (error) {
    // 拦截器已经显示了翻译后的错误 toast
    // 这里只需要处理业务逻辑（如停止 loading）
  }
};

// ❌ 不推荐：重复处理错误
const handleSubmit = async () => {
  try {
    await login({ email, password });
  } catch (error) {
    const { t } = useI18n();
    toast.error(t(`code.${error.code}`, error.msg)); // 重复了！
  }
};
```
